          <li>Components that render locale-sensitive output accept a <code>locale</code> prop (BCP 47 language tag, e.g. <code>"en-AU"</code>, <code>"ar-AE"</code>).</li>

          <li>No design-system component defaults to a hardcoded timezone. <code>Intl.DateTimeFormat</code> is always called with an explicit <code>timeZone</code> when one is provided.</li>
